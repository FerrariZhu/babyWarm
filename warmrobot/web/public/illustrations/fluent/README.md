Files are from `assets/<name>/Flat/<filename>` in that revision:

- Bear / bear_flat.svg — default avatar
- Rabbit / rabbit_flat.svg — default avatar
- Teddy bear / teddy_bear_flat.svg — login illustration (not an exclusive trademark)
- Memo / memo_flat.svg — empty dressing records
- Sun / sun_flat.svg — clear weather
- Sun behind cloud / sun_behind_cloud_flat.svg — partly cloudy / fallback
- Cloud / cloud_flat.svg — cloudy weather
- Cloud with rain / cloud_with_rain_flat.svg — rain
- Cloud with snow / cloud_with_snow_flat.svg — snow
- Cloud with lightning and rain / cloud_with_lightning_and_rain_flat.svg — thunder
- Fog / fog_flat.svg — fog

SVGs are served from this application, with explicit display dimensions and no
remote runtime image requests. These decorative images use empty alt text where
the adjacent label already supplies the meaning. User-uploaded avatars are kept.

The previous JPG defaults remain for old direct links; default-avatar resolution
now uses these licensed illustrations. The existing miniprogram-icon-144.png is
retained as the app identity. Clothing artwork stays in core/assets/garment-icons
with its existing Lucide (ISC) / IconPark (Apache-2.0) notices. Material Symbols
remain self-hosted through the existing package, without Google Fonts requests.
